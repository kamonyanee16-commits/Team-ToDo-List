# 📌 ระบบติดตามงานทีม (Team To Do List)
> **Kanban Board & Team Overview Dashboard**  
> เชื่อมต่อฐานข้อมูล **Google Sheets** และจัดเก็บไฟล์แนบบน **Google Drive** พร้อม Host บน **GitHub Pages**

---

## ✨ ฟังก์ชันเด่นของระบบ

1. **👑 หน้าหัวหน้างาน (Manager View):**
   - **ภาพรวมงานทั้งทีม (Team Overview):** แสดงสถิติงานทั้งหมด, งานที่กำลังทำ, งานรอตรวจ, งานที่เลย/ใกล้กำหนดส่ง, และงานที่เสร็จสิ้น
   - **สรุปภาระงานรายบุคคล (Workload Distribution):** ติดตามความคืบหน้าของสมาชิกแต่ละคน คลิกเพื่อสลับไปดูบอร์ดของสมาชิกคนนั้นได้ทันที
   - **สิทธิ์เต็มรูปแบบ:** สามารถมอบหมายงานให้ใครก็ได้ แก้ไข เคลื่อนย้ายสถานะ หรือลบงานของทุกคนได้

2. **👤 หน้าของทีมงานแต่ละคน (Member View):**
   - **บอร์ด Kanban ส่วนตัว:** มี 5 สถานะที่ใช้งานจริง:
     - 📋 **To Do (รอดำเนินการ)**
     - ⚡ **In Progress (กำลังทำ)**
     - 🔍 **In Review (รอตรวจ)**
     - ⏸️ **On Hold (พักไว้/ติดปัญหา)**
     - ✅ **Done (เสร็จสิ้น)**
   - **Drag & Drop:** ลากวางการ์ดงานเพื่อเปลี่ยนสถานะได้อย่างลื่นไหล
   - **การจำกัดสิทธิ์ (Permissions):** 
     - สามารถเพิ่ม แก้ไข และลากงานของตนเองได้เต็มที่
     - สามารถกดเลือกดูงานของเพื่อนร่วมทีมคนอื่นได้ แต่จะเป็นโหมด **"อ่านอย่างเดียว (Read-Only)"** ไม่สามารถเพิ่มหรือแก้ไขงานของคนอื่นได้

3. **📎 ข้อมูลงานและการแนบไฟล์ (Attachment):**
   - ข้อมูลครบครัน: ชื่องาน, รายละเอียด, ผู้รับผิดชอบ, ผู้สร้างงาน, วันที่เริ่ม, วันกำหนดส่ง (Deadline), สถานะ, ระดับความสำคัญ
   - ระบบแจ้งเตือนสี Deadline (เลยกำหนด, ครบกำหนดวันนี้, ใกล้ถึงกำหนด)
   - รองรับการแนบไฟล์ภาพ (พรีวิวรูปบนการ์ดงานได้ทันที) หรือไฟล์เอกสาร PDF/Word/Excel ซึ่งจะถูกส่งไปเก็บไว้ใน **Google Drive** โดยอัตโนมัติ

4. **⚡ สลับผู้ใช้งานได้ทันที (User Switcher):**
   - เลือกเปลี่ยนผู้ใช้งานจากมุมขวาบนได้ทันที:
     - 👑 **คุณ นาวิน บุญสุวรรณ (หัวหน้างาน)**
     - 👤 **คุณ กมลญาณี เฉลยพงษ์ (ทีมงาน)**
     - 👤 **คุณ ภัสสร อยู่ป้อม (ทีมงาน)**
     - 👤 **คุณ กลรัตน์ สกุลมา (ทีมงาน)**
     - 👤 **คุณ นัทธมน รอดแสวง (ทีมงาน)**

## 🚀 วิธีการติดตั้งและเชื่อมต่อ Google Sheets & Google Drive (ทำเพียงครั้งเดียว)

### ขั้นตอนที่ 1: เตรียม Google Sheets และ Google Apps Script
1. เปิดเว็บเบราว์เซอร์ไปที่ [sheets.new](https://sheets.new) เพื่อสร้าง Google Sheet เปล่าแผ่นใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `Team To Do Database`
3. ไปที่เมนูด้านบน: **ส่วนขยาย (Extensions)** > **Apps Script**
4. ลบโค้ดเริ่มต้นในหน้าจอออกให้หมด
5. เปิดไฟล์ `google-apps-script/Code.gs` ในโฟลเดอร์โปรเจกต์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางใน Apps Script
6. กดปุ่ม **บันทึกโครงการ (Save / รูปแผ่นดิสก์)**

### ขั้นตอนที่ 2: Deploy เป็น Web App (เพื่อให้หน้าเว็บเชื่อมต่อได้)
1. ที่หน้า Apps Script กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** มุมบนขวา > เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกไอคอนรูปฟันเฟืองข้าง "เลือกประเภท" > เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Team To Do API`
   - **ดำเนินการในฐานะ (Execute as):** `ตัวฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`  *(⚠️ สำคัญมาก ต้องเลือกเป็น Anyone เพื่อให้หน้าเว็บส่งข้อมูลได้)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. หากมีหน้าต่างขออนุญาตสิทธิ์เข้าถึง (Authorization Required) ให้กด **ตรวจสอบสิทธิ์ (Review Permissions)** > เลือกบัญชี Google ของคุณ > กด **Advanced (ขั้นสูง)** ด้านล่างซ้าย > กด **Go to ... (unsafe)** > กด **Allow (อนุญาต)**
6. เมื่อเสร็จสิ้น คุณจะได้รับ **URL ของเว็บแอป (Web app URL)** (รูปแบบ: `https://script.google.com/macros/s/.../exec`) ให้คัดลอก URL นี้ไว้

### ขั้นตอนที่ 3: นำ URL มาใส่ในระบบหน้าเว็บ
1. เปิดไฟล์ `index.html` บนเบราว์เซอร์ (หรือเข้าผ่านลิงก์ GitHub Pages)
2. คลิกปุ่ม **"เชื่อมต่อ Google Sheet"** ที่มุมบนขวา
3. วาง Web App URL ที่คัดลอกมาลงในช่องข้อความ
4. กดปุ่ม **"ทดสอบการเชื่อมต่อ"** เพื่อตรวจสอบความถูกต้อง (ระบบจะแจ้งเตือนว่าเชื่อมต่อสำเร็จ)
5. กดปุ่ม **"บันทึกการตั้งค่า"** — *ระบบจะดึงข้อมูลจริงจาก Google Sheet ทันที!*

## 🌐 วิธีการนำขึ้น GitHub และเปิดใช้งาน GitHub Pages (Host ฟรี)

### วิธีที่ 1: ผ่านหน้าเว็บ GitHub.com (ง่ายที่สุด ไม่ต้องใช้คำสั่ง)
1. ไปที่ [GitHub.com](https://github.com) แล้วสร้าง Repository ใหม่ (เลือกเป็น **Public**)
2. ในหน้า Repository กดปุ่ม **Add file** > **Upload files**
3. ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์โปรเจกต์นี้ (`index.html`, โฟลเดอร์ `css`, โฟลเดอร์ `js`, โฟลเดอร์ `google-apps-script`, `README.md`) ไปวาง
4. กด **Commit changes**
5. ไปที่แท็บ **Settings** ของ Repository > เมนูด้านซ้ายเลือก **Pages**
6. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** (หรือ `master`) และโฟลเดอร์เป็น **/(root)**
   - กด **Save**
7. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น `https://<your-username>.github.io/<repo-name>/` สามารถแชร์ให้ทีมงานทุกคนเปิดใช้งานได้ทันที!

### วิธีที่ 2: ผ่าน Git CLI (หากมี Git ติดตั้งในเครื่อง)
```bash
git init
git add .
git commit -m "Initial commit - Team To Do List"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
จากนั้นเข้าไปเปิด GitHub Pages ใน Settings ตามขั้นตอนด้านบน
